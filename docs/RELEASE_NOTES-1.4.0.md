# 岛仔 1.4.0 更新说明

> 发布版本：1.4.0。本版已合入上游 v0.6.70 的全部更新，下面只列自定义版本自身的改动；上游改动（插件集市、系统性能与无线设备页、底部停靠与跨屏拖动、日程按日期浏览与农历、邮箱仅提醒验证码、AI 额度 Antigravity 等）见 [上游 v0.6.70 发布说明](https://github.com/Renly1994/xiaotang-daozai/releases/tag/v0.6.70)。

## 这次更新的重点

1. **液态玻璃主题可选自动 / 深色 / 浅色**
   - 「配置液态玻璃」弹窗第一行新增主题模式：自动沿用原有的背景亮度采样，深色 / 浅色则固定，背景怎么变都不切换。
   - 设置写入 `settings.txt` 的 `liquid_theme=auto|dark|light`，诊断包也会收集。
2. **亮度自适应更准**
   - 背景亮度改为 WCAG 相对亮度与分区采样：玻璃上缘与内容区分开算，展开时以内容区为准，浅色背景上的文字对比度更稳。
   - 截尾中位数从整数组排序改为只定位分位点，采样更快。
3. **液态玻璃观感与稳定性**
   - 跨屏拖动到副屏后玻璃背景不再错乱；上游的跨屏拖动与底部停靠已落地到本定制版的 D3D11 自绘栈。
4. **剪贴板历史支持图片**
   - 复制的图片（截图、浏览器 / 聊天里的图）会进入「剪贴板」历史，显示缩略图，点击即可复制回去。
   - 单张上限约 4000×4000 / 12 MB；固定条目长期保留，未固定条目 24 小时后清理。
5. **安装与数据目录独立**
   - 安装包改用 Inno Setup，默认装到 `C:\Program Files\DaozaiCustom`，安装时可自选目录。
   - 用户数据统一放在 `%APPDATA%\DaozaiCustom`，升级和卸载都不会动它。

## 用户可见变化

- 「配置液态玻璃」多了主题模式选择，浅色背景下展开面板的文字更清楚。
- 图标不再闪；跨屏后玻璃背景不再错乱。
- 图片复制可随时从剪贴板历史找回。
- 诊断包现在直接带上应用日志（玻璃、音量、验证码、通知、邮件等），在「设置 → 关于 → 收集诊断」一键生成 ZIP。

## 已知事项

- 跨屏换屏瞬间约有 1 秒回退纯色（抓屏会话重建），属正常。
- 字体「毛刺」仍无上游直接修复项；如仍复现，请附截图、字号和 Windows 显示缩放比例。
