# 岛仔 1.3.0 更新说明

> 发布版本：1.3.0，基于 egui 0.37（上游提交 `56f3a0e`）。

## 这次更新的重点

1. **界面内核升级到 egui 0.37**
   - 基于 egui 上游提交 `56f3a0e`。
   - 适配 0.37 的截图回调、窗口命令、纹理增量、输入事件、可访问性角色等接口变化。
   - 修复升级后出现的图标裁切、测试辅助窗口、立即视口等兼容问题。
2. **文字与字体**
   - 启用 egui 0.37 的系统字体回退，缺字时优先使用系统字体而不是内置兜底字体。
   - 打开 `system_fonts`、`monochrome_emoji_fonts`，改善中文、符号与 emoji 的覆盖。
   - 保留岛仔原有的 Segoe / 微软雅黑 / Noto 多字重字体链。
3. **D3D11 渲染与显卡选择**
   - 实现“优先独立显卡”的真实选卡逻辑：启动时枚举 DXGI 适配器，跳过软件显卡，优先独立显存更大的独显；没有独显时回退默认显卡。
   - 关闭该开关时保持原来的默认适配器行为。
   - 选卡快照改为显式传参，不再依赖全局环境变量。
   - D3D11 纹理采样改为双线性过滤 + 点 mip 过滤，避免字体图集被采样到无关的 mip 层。
   - 修复 D3D11 `Primitive::Clear` 与透明子窗口的渲染兼容问题。
4. **设置窗口体验**

- 设置页截图、窗口恢复、焦点请求、字体设置等流程按 egui 0.37 接口重新适配。
- “优先独立显卡”设置说明同步更新为新选卡策略。

1. **稳定性与工程清理**
   - 清理所有 egui 0.35 过时 API 调用。
   - 修复消息提醒测试辅助进程自然退出导致的偶发失败。

## 用户可见变化

- 中文、符号、emoji 的缺字回退更稳。
- 混合显卡机器开启“优先独立显卡”后，启动时会实际选择独显。
- 更新弹窗、截图、子窗口交互迁移到 egui 0.37 新接口。
- 过时 API 调用清理完成，为后续升级减少兼容负担。

## 已知事项

- 字体“毛刺”没有上游直接修复项；本版本通过系统字体回退与采样策略改善，是否完全符合预期需实机确认。
