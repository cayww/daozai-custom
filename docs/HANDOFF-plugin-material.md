## 二、部分合并

1. **保持展开整套**（`1918f17`）
   - 已有：`hold_slot` 字段与少量占位。

   - 影响：置物架/剪贴板保持展开、切页顶栏稳定性。

2. **翻页箭头锚点**（`0c216b6` / `ccfd0e8` / `9263a7e` / `216cd2a`）

   - 本地用 D3D11 自绘栈替代；属架构定制，不按缺失处理。

5. **官方集市测试索引夹具**

6. **手机连接短信/来电转发**
