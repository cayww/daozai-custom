# 更新记录

## v0.6.64 · 自定义构建

- 优化：剪贴板大量历史时不再每帧复制、不再在界面线程写盘，粘贴大段文本更跟手；会议自动勿扰改为缓存日程，减少后台计算。
- 优化：通知历史与专注统计改为原子写，文件意外损坏时会先备份成 `.bad` 而不是把历史清空；外部配置文件限制 1 MB。
- 隐私：通知历史和验证码日志里的验证码改为打码保存；未固定的剪贴板内容只保留 24 小时（固定的片段模板不受影响）。
- 安全：状态卡片的「打开文件」动作只放行存在的非可执行文件。

- 新增：验证码卡片停留时间可调（设置「通知」→ 验证码停留，10–300 秒，默认 90 秒）。它不会短于「通知停留」、也不会低于 10 秒，保证有时间回看和点「复制」。

- 新增：通知停留时长可调。设置「通知」→ 通知停留（2–120 秒，默认 10 秒），到时自动收起，不用手动点关闭；验证码卡片至少留 90 秒方便回看。原来的「重复查看通知」开关自动折算成对应秒数。

- 新增：通知规则引擎。`notice-rules.json` 里写「正则 + 动作」，可静音（mute）、高亮（highlight）、自动复制正文（copy），按顺序第一条生效，改完 1 秒热生效；设置「通知」里可直接打开规则文件。
- 新增：AI 额度阈值提醒。任一额度窗口剩余跌破 20%（可调 10/20/30%）时提醒一次，回升后下次还能提醒。
- 新增：一键备份配置。设置「常规」→ 备份，把配置与状态复制到 `backups/<时间戳>/`，完成后自动打开目录。
- 调整：「最近通知」挪到通知页顶部，不用滚到底。

- 新增：会议自动勿扰。日程一开始就自动勿扰到散会（最多 2 小时），散会解除；可在设置「通知」里关掉。
- 新增：通知历史。每条通知落到 `notices.json`（最多 100 条），设置「通知」页可直接看最近 8 条：点一行复制正文，点「稍后」5 分钟后再提醒一次。
- 新增：剪贴板键盘操作。搜索框里 ↑↓ 选行、Enter 复制，选中行会高亮并自动滚动到可视区。
- 新增：专注统计。设置「专注」页显示今日专注时长与连续天数，只统计真正在跑的阶段（暂停不计）。

- 修复：开机后头一分钟到达的手机通知可能被当成「启动历史」吞掉。现在首轮枚举会补报「线程启动之后才创建」的通知，比启动早的历史仍然不回放。
- 修复：4 位验证码正好落在 1900–2100（如 2084）时被当成「年份」而识别失败；现在只有后面紧跟日期成分（`2026-10-30`、`2026年`）才当年份。另外「验证码1234」「验证码 1234」这类没有冒号的写法也能识别了。
- 修复：手机连接的通知通道判定改为「凡 `Microsoft.YourPhone_` 开头都算手机通知」，开机后子通道未注册时不会再被漏掉；监听线程拦截的通知也会写进 `notice.log`，不再静默丢弃。

- 新增：来电中提示。手机上响铃时岛上显示「来电中 / 号码 正在呼叫」，挂断后才变成「未接来电」；新短信或来电会顶掉正在显示的上一条手机通知。
- 修复：短信被认成「手机 · 连接」。手机镜像通知的正文以手机号开头，原逻辑按「来源 App 名」识别，认不出就退化成「连接」；现在按正文特征区分短信（号码 /【签名】/验证码）、来电和普通 App，短信会正常显示为「手机 · 短信」并给大号验证码。
- 新增：`diagnostics/notice.log`。每条通知都会记一行「显示 / 被哪一步拦下」+ 原始应用 id 与正文，以后再遇到「某类通知不上岛」可直接查。

- 新增：勿扰。设置「通知」页可选 30 / 60 / 120 分钟，期间不弹横幅、不闪铃铛、不发系统通知；通知历史照记、验证码照提醒，到点自动解除。
- 新增：状态总线支持 `priority` 与 `ttl`。高优先级抢占前三格，`ttl` 到点的状态自动撤下，脚本写完不用再管。
- 新增：状态总线的按钮可以指挥岛仔了——`action:focus_start` / `action:quiet30` / `action:page:5` 等五个白名单动作，配合脚本做「构建开始就进专注」。
- 新增：低电提醒阈值可选（关 / 10% / 20% / 30%），本机与手机共用，本机充满时也会提示。
- 新增：通知关键词高亮。命中词表（验证码 / 面试 / 转账 / 取件等）时提示卡片左侧亮一条琥珀色竖条，词表可在 `settings.txt` 里改。
- 新增：剪贴板支持搜索。分栏右上多了放大镜，点开后浮出输入框（蓝框闪烁光标），输入即筛选，Esc 或小叉收起。
- 新增：邮件面板记住上次选的账号，重启后沿用；回收站页也补上了账号选框。
- 调整：本机电量与手机电量彻底分开。「电量」只管本机（电脑）电池，「手机电量」只管「手机连接」上报的电量，两个开关互不影响；同时开启时并排显示两个环。没装「手机连接」时「手机电量」开关置灰不可点。

- 调整：岛上歌词的左右留白。原来左侧离宠物太远、右侧紧贴播放指示图标；现在左边收小、右边留出约一个字宽的空隙。
- 新增：岛上歌词超长时改为横向滚动。原来先缩字号（11pt→8pt），仍放不下就按播放进度分段显示、一句被切碎；现在缩到 8pt 还放不下会回到 11pt 单行，句首停留后匀速左移、到句尾停住，换句复位。短歌词仍按原样居中显示。

## v0.6.63

**邮箱整理更方便**

- 新增「全部／未读」筛选，显示当前已加载邮件的数量。打开邮件后自动标为已读，也可以手动切换已读、未读状态。
- 新增「全部已读」、回收站和邮件恢复。列表、详情页、独立全文窗口都支持相应操作。
- 默认只在本机整理，已读、删除等状态可在重启后保留。
- 新增「同步邮件操作到邮箱」开关，开启后将后续的已读、删除和恢复操作同步至真实邮箱。之前的本机操作会保留，切换开关时不会批量补交。
- 「全部已读」在本机模式下处理当前加载的记录，开启同步后处理已连接邮箱的全部未读邮件。
- 改善不同邮箱回收站的识别。远程删除、恢复需要邮箱支持安全移动邮件，暂不支持的邮箱可以使用本机整理。
- 同步失败时保留邮件记录并提示原因，多个邮箱分别反馈操作结果。
- 修复刷新后，本机已删除邮件重新回到收件箱的问题。
- 修复收件箱和回收站的数量限制互相影响，导致回收站记录提前减少的问题。

**收信与邮件阅读更稳定**

- 改善 163、126 等邮箱的定时收信连接，等待查信时最多每 45 秒保活一次，查信频率按用户设置执行。
- 自动适配邮箱的推送和定时收信能力，服务器拒绝某种收信方式时采用兼容方式处理。
- 断线重连后先补收期间的新邮件，再恢复正常监听。
- 新邮件按先后顺序分批收取，修复短时间来信较多时可能漏掉前面邮件的问题。中途失败后可继续补收。
- 首次加载失败后可以完整重试，邮箱内部邮件编号变化后会重新核对收取进度。
- 优化连接失败后的重试和无新邮件时的等待，减少反复重连、后台空转。
- 刷新邮件状态时优先复用已读取的正文，减少重复下载。
- 修复新验证码刚到达就提前隐藏的问题，改善主动查看验证码后，在新邮件到达、切换回收站等情况下的显示。
- 修复旧阅读窗口在切换文件夹、修改账号或邮箱数据变化后，可能操作到其他邮件的问题。
- 邮件被删除、恢复或移走，以及邮箱账号被停用、修改、移除后，及时更新列表和阅读窗口。
- 修复阅读邮件时滚动标题等区域，意外切换功能页的问题，并调整列表布局，保证底部邮件正常显示、点击。

**微信双开、多开适配**

- 改进微信提醒与所属账号的匹配，分别定位各账号的主窗口和托盘图标，兼顾双开及三个以上账号的情况。
- 点击提醒后核对实际打开的账号，确认对应窗口已到前台后再清除提醒。
- 无法直接获取图标位置时，会结合其他账号的位置辅助定位。无法唯一确认目标时提示手动打开。
- 点击前重新检查按钮位置，改善账号退出、托盘图标移动或布局变化时的误定位。
- 适配任务栏自动隐藏、图标收在折叠区，以及折叠区已经展开等情况。
- 改善新版 Windows 托盘按钮的查找和等待，排除微信输入法等相似名称。
- 修复岛仔以管理员身份运行时，可能收不到微信提醒的问题。
- 加强监听启动、权限和唤起失败的诊断记录，方便反馈和定位问题。

**通知设置与窗口唤起**

- 将原「岛仔提醒」明确标为「提醒总开关」，说明其对饮水、专注、待办、微信和 QQ 提醒的影响。
- 总开关关闭时，微信、QQ 相关设置置灰并显示原因，方便检查为什么没有提醒。
- 改进窗口激活，修复打开岛仔窗口时，可能误触其他软件 Alt 语音或快捷键的问题。
- 改善再次启动岛仔时对已有窗口的唤起。

**Claude 额度采集与 AI 额度页面**

- Claude 桌面端改为读取本机用量历史和缓存，Claude Code 支持通过官方状态栏提供额度数据。
- 新增「读取桌面版本地记录」「启用 Code 本地采集」入口，也可选择本地用量文件，并补充数据来源和连接说明。
- 完善不同安装位置的识别，兼容常见桌面安装、商店版，以及旧版账号配置和缓存。
- 改善压缩缓存、暂时读取不到、正在更新或损坏数据的处理，并限制异常数据的读取开销。
- 有有效重置时间时自动显示，缺少可靠记录时显示「重置时间未知」。
- 显示真实的记录时间，旧数据会提示等待客户端更新。已确认属于该账号的记录，可在 Claude 关闭及岛仔重启后继续查看。
- 修复切换账号、切换组织，以及同一组织内账号来回切换时，额度可能串号的问题。
- 启用 Claude Code 本地采集时会检查现有配置，保留已有状态栏和其他设置。
- 各 AI 额度来源统一显示更新时间，跨天记录带日期，并区分读取中、更新中、本地记录和上次记录。
- 调整额度页面高度、翻页按钮和点击范围，改善百分比、重置时间、积分、余额及长提示文字的排版。

**待办与中文输入**
