岛仔 Daozai v1.0.1 — 零拷贝抓屏实验版
====================================

这是 spike/wgc-gpu-share 分支的测试包，用于验证「去掉 WGC Map(READ) 同步读回」的零拷贝抓屏。
和 v1.0.0 的唯一功能差异：液态玻璃配置里多了一个开关。

怎么启用
  1. 打开设置 → 外观 → 液态玻璃配置
  2. 勾选「零拷贝抓屏（实验）」
  3. 重启岛仔（必须重启：抓屏设备在启动期创建）
  默认关闭。不勾选则和 v1.0.0 行为完全一致。

开关怎么工作
  勾选后，WGC 的帧不再「D3D11 staging → CPU 读回 → 上传回 GPU」，
  而是 D3D11 共享纹理 → wgpu(D3D12) 直接导入同一块显存 → shader 采样。
  理论收益：省掉每帧一次 GPU 同步等待 + 两次 ~1MB 拷贝。

测试要看什么
  - 玻璃背景是否正常（无「玻璃里显示玻璃」重影、无黑块/条纹/花屏）
  - 展开/折叠动画是否流畅、有无错位
  - CPU 占用是否比 v1.0.0 低
  - 稳定性：连续用一段时间有没有崩溃、卡死、玻璃冻结

诊断日志
  %APPDATA%\Daozai\diagnostics\liquid-glass.log
  开启时会出现：
    wgc: D3D11 设备绑定到 wgpu 同卡 adapter: "NVIDIA ..."
    wgc: GPU 共享纹理已创建 / [gpu-share] frame N / [gpu-share] 导入共享纹理 WxH
    exclude: 检查 #N 窗口...（WDA 排除，必须出现，否则会有自我反馈重影）
  若看到「退回 staging」或没有 [gpu-share] 行，说明自动回退到了旧路径。

异常时怎么办
  关掉设置里的「零拷贝抓屏（实验）」并重启，即回到 v1.0.0 的旧路径。
  本开关默认关闭、可随时切换，就是为了方便 A/B 对比。

其他说明
  - 安装会覆盖同目录的 v1.0.0；设置和记录（%APPDATA%\Daozai）保留。
  - 更新检查不会提示升级（当前版本 1.0.1 > GitHub 上的 v1.0.0）。
  - 源码分支：spike/wgc-gpu-share（未合并 main、未 push）。
    完整设计与风险见仓库 docs/WGC-GPU-SHARE-SPIKE.md。
  - 仅 Windows + 液态皮肤 + D3D12 兼容渲染下有效；其它情况开关无作用。
