岛仔 Daozai（自定义构建 custom-85）
====================================

安装内容
  daozai.exe            主程序（灵动岛）
  bridge\extension\     浏览器扩展（岛仔状态桥，Chrome/Edge 通用）
  bridge\daozai_bridge.exe   浏览器扩展桥宿主（主程序副本）
  注册表（HKCU）：浏览器 Native Messaging 宿主 + 开机自启 + 卸载信息

启用浏览器下载进度上岛（一次性，两步）
  1. 安装包已注册好桥宿主（本机程序 + 注册表）。
  2. 更简单：岛仔设置 → 通知 →「浏览器下载」→ 点「连接 Chrome/Edge」，
     会同时打开浏览器扩展页和 extension 文件夹，把文件夹拖进去即可。
     （手动路径：chrome://extensions 开开发者模式 →「加载已解压的扩展程序」
     → 选本目录的 bridge\extension 文件夹。）

之后浏览器里的下载会实时显示在灵动岛上：
  蓝色胶囊 = 下载中（进度条 + 速度）；绿色 = 完成（点一下打开文件）。

说明
  - 用户数据在 %APPDATA%\Daozai，升级安装与卸载都不会动它。
  - 设置页里可关闭检查更新（自定义构建默认关闭）。
